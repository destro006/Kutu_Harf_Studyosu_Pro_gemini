# Nesting engine
Research: SVGNest (MIT, https://github.com/Jack000/SVGnest), Deepnest Next (mixed licences, https://github.com/deepnest-next/deepnest), libnest2d (LGPL, https://github.com/tamasmeszaros/libnest2d), Sparrow (MIT, https://github.com/JeroenGar/sparrow), jagua-rs (MPL-2.0), Nestbolt (MIT, https://github.com/skulitom/Nestbolt).
Implementation: pinned Clipper JS 6.4.2 (Boost Software License), integer Minkowski sums / offsets / polygon difference generate feasible translation candidates. Multi-order search with sequence mutation, baseline retained. No claim that the entire upstream SVGNest, Sparrow or Nestbolt solver is embedded. Search proxies may be simplified; original contours are never simplified for output. Independent clearance and collision verification is mandatory. No mirroring. Respect rotation settings, material batching, locked placements, margins, and hole nesting switch. Fixed-sheet scrap is unchanged for identical area and sheet count; compact-envelope and reusable offcut are separate metrics.
